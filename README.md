# dk-ai-lab

찾아가는 AI교육서비스팀이 강의에서 쓴 실습키트와 skill을 나누는 저장소입니다.
수업에서 받은 파일을 다시 받거나, 수업에 오지 못한 분이 같은 자료로 따라 해 볼 수 있습니다.

## 폴더 구조

```
dk-ai-lab/
├─ 01_강의자료/          과정별 강의 실습 자료
├─ 02_AI도구/            강의에서 나눠 준 실습 세트 (작업실·스타터키트 등)
│   └─ NN_<세트 이름>/
│       ├─ README.md     소개 · 다운로드 링크 · 사용법 · 버전 기록
│       └─ (세트 파일)
├─ 03_DK스킬/           팀이 만든 skill
│   └─ NN_<skill 이름>/
│       ├─ README.md     소개 · 다운로드 링크 · 등록 방법 · 버전 기록
│       └─ (skill 파일)
└─ 04_사외스킬/         다른 곳에서 만들어 공개한 skill (파일 없이 안내만)
                         ※ 받기 전에 01_스킬보안점검(SkillSpector)으로 먼저 검사 권장
    └─ NN_<skill 이름>/
        └─ README.md     만든 곳 · 목적 · 원본 주소 · 설치 방법
```

- 세트와 skill 이름은 강의에서 부른 이름 그대로입니다.
- 번호는 올린 순서입니다.

## 받는 법

1. 위 폴더에서 필요한 세트나 skill 폴더를 엽니다.
2. 파일 목록 아래에 보이는 README의 **다운로드** 링크를 눌러 zip을 받습니다.
3. 압축을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 클릭 → 속성 → 「차단 해제」를 체크하고 확인을 누릅니다.
4. 압축을 풀고 README의 사용법대로 진행합니다.

3번을 하지 않으면 `.bat` 파일을 실행할 때 「Windows의 PC 보호」 경고가 뜹니다.
DK스킬 zip은 압축을 풀지 않고, 쓰고 있는 AI 서비스(ChatGPT, Claude 등)의 skill 설치 메뉴에 그대로 올립니다.
화면 오른쪽 위 Code → Download ZIP은 저장소 전체를 받으므로 쓰지 않습니다. 필요한 것만 README 링크로 받습니다.

## 올리는 방식

- 세트와 skill은 하나씩 **Release**에 zip으로 올리고, 각 README에 그 zip 링크를 겁니다.
- 내용을 고치면 새 버전(`v2`, `v3` …)으로 다시 올리고 README 링크를 최신 버전으로 바꿉니다. 바뀐 점은 README의 버전 기록에 남깁니다.
- 이전 버전은 [Releases](https://github.com/dkaieduteam/dk-ai-lab/releases)에 그대로 남아 있습니다.
- 공개 저장소라 실제 사내 문서와 개인 정보는 넣지 않습니다. 실습 자료는 모두 가상 데이터입니다.
