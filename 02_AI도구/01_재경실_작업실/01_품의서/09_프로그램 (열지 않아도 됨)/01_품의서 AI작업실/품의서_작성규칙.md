# 품의서 작성 규칙

전자결재 품의서 본문 HTML이 따라야 하는 기준이다. 사람은 HTML 파일을 메모장으로 열어 전자결재 본문 편집기의 HTML 편집 화면에 붙여넣는다.
쓰는 법은 「재경실 품의서 작성 Guide」(1절)를 따르고, HTML 모양은 `품의서_HTML틀.html`을 따른다.
품의서 HTML은 `프로그램\변환.py`가 만든다. 결과가 이 기준과 다르면 프로그램을 고친다.
Guide 규칙 가운데 글꼴 · 글자 크기 · 줄간격(1절 1번)은 줄마다 전자결재 편집기와 같은 모양의 `style`로 넣는다.

## 1. 재경실 품의서 작성 Guide

1. 편집기는 본고딕, 12pt, 줄간격 1.5로 기본 설정한 뒤 작성을 시작한다 (HTML 줄마다 `style`로 넣는다)
2. 문단 처음에는 공백 5~6칸을 넣고 쓴다 (편집기 위 「품의유형」 글씨와 앞 끝이 대략 맞도록)
3. 「아래」 줄은 빼기(-) 5개 + 공백 5칸 + `아` + 공백 5칸 + `래` + 공백 5칸 + 빼기(-) 5개를 왼쪽 정렬로 가운데쯤에 쓴다 → `-----     아     래     -----`. 가운데 정렬은 쓰지 않는다 (보는 문서에 따라 엉뚱한 위치에 보일 수 있음). 앞에 공백을 넣어 가운데로 옮긴다
4. 한 칸 띄우기 : 본문 맨 위, 서두와 「아래」 줄 사이, 「아래」 줄과 첫 번호 사이, 큰 번호 항목 사이에 빈 줄 한 줄을 둔다
5. 문서 작성 체계 : `1.` > `가.` > `(1)` > `(가)` > 이후 하이픈(`-`) 혹은 점
6. 하이픈 뒤에는 점을 굳이 붙이지 않는다 (`-.` 아님)
7. 하위 단계는 대략적으로 줄을 맞춘다. 윗 단계 번호 뒤 글자가 시작하는 위치쯤에서 하위 번호를 시작한다
8. 맨 끝은 `끝.`으로 맺는다

## 2. HTML 작성 규칙

`품의서_HTML틀.html`을 열어 같은 방식으로 쓴다.

- 결과는 품의서 한 건마다 HTML 파일 하나
- 한 줄 = `<p style="font-family: 본고딕; font-size: 12pt; line-height: 1.5; margin-top: 0px; margin-bottom: 0px;">` 하나. 빈 줄은 같은 `<p style="…">` 안에 `<br>`만 (`변환설정.json`의 `문단_스타일`)
- 한 줄은 전자결재 한 줄 폭(본고딕 12pt 한글 48.5자, `한줄_최대폭`)을 넘지 않는다. 넘으면 띄어쓰기 자리에서 미리 나누고, 다음 줄은 번호 뒤 글자 위치(번호 없는 이어짐 줄과 같은 위치)에서 시작한다. 띄어쓰기가 없으면 폭에 맞춰 자른다
- 공백은 모두 `&nbsp;`로 쓴다. 일반 띄어쓰기를 여러 개 쓰면 편집기가 하나로 줄인다. 글자 사이 한 칸 띄어쓰기는 일반 공백으로 써도 된다
- 표를 쓸 때는 `<table>`에 `border="1"`, `style="border-collapse:collapse;margin-left:…"`를 넣고, 칸마다 `style="padding:4px 8px;font-family:본고딕;font-size:12pt"`를 준다. `margin-left`는 표가 윗 줄 글자 위치쯤에서 시작하도록 정한다
- 색은 지정하지 않는다 (`color` 쓰지 않음)
- 스크립트 · 외부 이미지 · 외부 링크 · 외부 CSS를 넣지 않는다

## 3. 점검표

| 항목 | 기준 |
|---|---|
| 문단 처음 | 서두와 큰 번호 줄이 공백 5~6칸으로 시작 |
| 「아래」 줄 | `-----     아     래     -----`, 가운데 정렬 없이 앞 공백으로 가운데쯤 |
| 한 칸 띄우기 | 본문 맨 위 · 서두 다음 · 「아래」 줄 다음 · 큰 번호 항목 사이에 빈 줄 한 줄 |
| 번호 | 1. > 가. > (1) > (가) > - (하이픈 뒤 점 없음) |
| 줄맞춤 | 하위 번호가 윗 단계 글자 위치쯤에서 시작 |
| 끝 | 맨 끝이 `끝.` |
| 글꼴 | 줄마다 본고딕 · 12pt · 줄간격 1.5, 빈 줄은 `<br>` |
| 줄 폭 | 한 줄이 한글 48.5자 폭 안. 긴 줄은 띄어쓰기 자리에서 나누고 다음 줄은 번호 뒤 글자 위치 |
| HTML | 공백 `&nbsp;`, 색 지정 없음, 스크립트 · 외부 링크 없음 |

## 4. 추가 규칙

실습하면서 고친 점을 여기에 한 줄씩 쌓는다.

- 번호는 원문 기호 모양이 아니라 깊이로 다시 매긴다. `1)`의 윗 단계가 `1.`이면 `가.`, `□` → `1.`, `○` → `가.`, `-`는 그대로 (`-` 아래의 `-`는 `·`)
- 깊이별 앞 공백은 5 / 8 / 12 / 16 / 21칸 (`변환설정.json`의 `깊이별_앞공백`). 번호 없는 이어짐 줄은 윗 항목 글자 위치
- 원문에 「아래」 줄이 없으면 넣지 않는다 (`아래줄_없으면_넣기`: false). `- 아 래 -` · `-다음-` · `【아래】` 같은 변형은 Guide 「아래」 줄로 바꾼다
- 붙임 다음 따로 줄로 쓴 끝 표시는 붙임 마지막 줄 끝으로 옮겨 두 칸 띄우고 `끝.`
- `제목 : …` 줄은 남긴다 (`제목줄_빼기`: false)
- 표 바로 위의 `(단위 : 원)` 같은 줄은 글자 끝이 표 오른쪽 끝에 오도록 앞 공백을 넣는다
- 날짜 · 금액 · 번호 값은 고치지 않는다
