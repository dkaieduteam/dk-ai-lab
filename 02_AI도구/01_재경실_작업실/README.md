# 재경실 작업실

재경실 워크샵(품의서·출장복명)에서 쓰는 실습 세트입니다.

## 다운로드

[jaegyeong-workroom.zip 받기 (v2)](https://github.com/dkaieduteam/dk-ai-lab/releases/download/jaegyeong-v2/jaegyeong-workroom.zip)

## 받은 뒤 할 일

1. `jaegyeong-workroom.zip`을 받습니다.
2. 압축을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 클릭 → 속성 → 「차단 해제」를 체크하고 확인을 누릅니다.
3. 압축을 풀고 `재경실_작업실` 폴더를 엽니다.

2번을 하지 않으면 `.bat` 파일을 실행할 때 「Windows의 PC 보호」 경고가 뜹니다.

## 사용법

ChatGPT 데스크탑 앱에서 진행합니다. 앱이 없으면 https://chatgpt.com/download 에서 설치합니다. 앱에서 「파일」 → 「폴더 열기」로 폴더를 고르고 「폴더 신뢰」를 누르면 그 폴더에서 일합니다.

### 01_품의서 — 품의서를 전자결재 HTML로 바꾸기

1. `01_품의서 넣기` 폴더에 품의서 파일을 넣습니다 (txt · docx · pptx · xlsx · pdf · hwpx).
2. `품의서 만들기.bat`을 더블클릭하면 브라우저에 결과 페이지가 열립니다.
3. 서식이 맞으면 「HTML 코드 복사」를 눌러 전자결재 본문 편집기의 HTML 편집 화면에 붙여 넣습니다.
4. 서식이 다르면 ChatGPT 앱에서 `09_프로그램 (열지 않아도 됨)` 안의 `01_품의서 AI작업실` 폴더를 열고, 건 번호와 줄 번호로 고칠 곳을 말합니다. (예: 건0003 9번 줄 바로 아래에 표가 들어가야 해. 이것만 고쳐 줘.)
5. AI가 고쳤다고 하면 `품의서 만들기.bat`을 다시 실행합니다.
6. 새 버전이 마음에 들지 않으면 `이전 버전으로.bat`을 실행합니다.

품의 내용은 AI에게 주지 않습니다. HTML 변환은 내 PC의 프로그램이 하고, AI는 그 프로그램만 고칩니다.
자세한 순서는 `01_품의서/사용법.md`에 있습니다. 실습용 품의 샘플 PPTX는 포함하지 않으므로 본인 품의서나 가상 문서로 진행합니다.

### 02_출장복명 — 영수증으로 복명서 만들고 skill로 등록하기

1. ChatGPT 앱에서 `02_출장복명` 폴더를 엽니다.
2. 새 채팅에서 영수증 폴더를 지정해 만들어 달라고 요청합니다.
   ```
   1112~13_포항 폴더의 영수증 이미지를 모두 읽고,
   출장정산_규칙.md대로 출장 복명 엑셀과 기타보고를 바로 만들어 줘.
   ```
   AI가 `출장정산_규칙.md`를 따라 영수증을 읽고, `09_프로그램 (열지 않아도 됨)` 안의 `복명서_생성.py`로 회사 양식 xlsx를 채웁니다. 1박 이상은 출장 복명, 당일은 외근 복명입니다. 결과 파일은 영수증 폴더 안에 생깁니다.
3. 같은 대화에서 이 방식을 skill로 만들어 설치까지 시킵니다.
   ```
   지금까지 만든 방식을 "trip-report" skill로 만들어 줘.
   출장정산_규칙.md, 양식 두 개, 09_프로그램 폴더의 복명서_생성.py를 skill 안에 넣고, 묻지 않고 바로 만들게 해 줘.
   자료에 없는 값은 지어내지 말고 비워 둔 뒤 "확인 필요"로 알려 주게 해 줘.
   만든 뒤 설치까지 해 줘.
   ```
4. 새 채팅에서 `$trip` → 「Trip Report」를 고르고 `1117~19_부산 폴더로 만들어 줘.` 한 줄로 만듭니다.
5. skill을 지울 때도 채팅으로 합니다: `trip-report skill을 이 PC에서 지워 줘. 02_출장복명 안의 skill 원본 폴더는 그대로 둬.`

영수증 폴더 5개(`1112~13_포항` · `1117~19_부산` · `1120_대전` · `1124~25_광주` · `1127_당진`)는 실습용 가상 영수증입니다. 숙박비는 1박 70,000원까지만 넣습니다.
