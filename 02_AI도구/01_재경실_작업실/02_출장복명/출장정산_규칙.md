# 출장정산 규칙

출장·외근을 다녀온 뒤 영수증 이미지로 복명서 첨부 엑셀(xlsx)과 전자결재 본문(txt)을 만든다.
1박 이상이면 "출장 복명", 당일이면 "외근 복명".

## 하는 일 / 하지 않는 일

| | |
|---|---|
| 한다 | 영수증 이미지를 읽어 날짜·구간·금액·박 수 파악 → 양식에 채우고 영수증 첨부 → xlsx 생성 |
| 한다 | 식비·잡비 횟수 산정, 법인·개인 카드 구분, 기타보고 txt(칸 제목만) 생성 |
| 하지 않는다 | 결재 상신. 사람이 열어서 확인하고 올린다 |
| 하지 않는다 | 묻고 기다리기. 영수증을 읽으면 바로 만든다 |
| 하지 않는다 | 영수증이 없는 항목을 추측해서 채우기. 비워 두고 만든 뒤 "확인 필요"로 알린다 |
| 하지 않는다 | 부서·이름을 묻거나 넣기. 출장 목적·내용을 지어내기 (기타보고는 칸 제목만 두고 사람이 채운다) |

## 1. 영수증 폴더와 결과 파일

영수증은 출장마다 `날짜_출장지` 폴더에 모은다. 예: `1112~13_포항` (11/12~13 포항), `1120_대전` (11/20 당일).
결과 엑셀 · 기타보고 · `spec.json`은 **그 영수증 폴더 안에** 만든다.

| 출장 형태 | 양식 파일 | 결과 파일 이름 |
|---|---|---|
| 1박 이상 | `양식_출장복명_1박이상.xlsx` | `출장 복명_{출장지}_{출장 시작일 YYMMDD}.xlsx` |
| 당일 | `양식_외근복명_당일.xlsx` | `외근 복명_{출장지}_{외근일 YYMMDD}.xlsx` |

- 출장지 = 영수증 폴더 이름의 `_` 뒤 (예: `1112~13_포항` → `포항`). 폴더 이름에 없으면 KTX 도착역의 도시 이름 (예: 광주송정 → 광주)
- 파일 이름의 날짜는 작성일이 아니라 출장 시작일 (영수증에서 읽은 날짜). 예: `출장 복명_포항_261112.xlsx`
- 같은 이름의 결과 파일이 이미 있으면 묻지 않고 이름 끝에 `_2`(있으면 `_3` …)를 붙여 새로 만든다. 사용자가 덮어쓰라고 하면 덮어쓴다
- 부서 · 이름은 파일 이름에도 엑셀에도 넣지 않는다
- 채우는 시트는 3번째 시트 하나. 앞의 `당일`·`1박 이상` 시트는 빈 양식 그대로 둔다
- 3번째 시트 이름은 이동수단에 맞춘다. KTX·버스 = `대중교통`, 회사차·자차 = `자가차량` (예: `1박 이상 대중교통`)

## 2. 영수증에서 읽을 것

이미지를 직접 열어서 읽는다. 파일 이름은 믿지 않는다. 파일 이름과 영수증 내용이 다르면 영수증이 우선이다.

| 영수증 | 읽는 값 |
|---|---|
| KTX 승차권 | 이용일자, 출발 → 도착, 총 영수 금액, 카드번호 |
| 숙박 예약내역 | 숙소명, 체크인·체크아웃, 박 수 |
| 숙박 매출전표 | 합계 = 실결제액 (공급가액이 아님), 카드번호 |
| 지도 길찾기 화면 (자가차량) | 출발 → 도착, 통행료, 연료비 |

- 박 수는 예약내역의 체크인·체크아웃으로 정한다. 결제일시는 예약한 날이지 숙박한 날이 아니다
- KTX는 승차권 한 장에 영수증 한 장. 가는편 · 오는편을 합쳐 교통비 한 줄로 쓴다
- 지도 화면에는 날짜가 없다. 자가차량 외근 날짜는 영수증 폴더 이름에서 읽는다 (예: `1127_당진` → 2026.11.27)
- 읽은 값을 확인받지 않고 바로 엑셀을 만든다. 다 만든 뒤 읽은 값을 표로 보여 준다

## 3. 금액·횟수

```
합계 = 교통비 + 숙박비 + 식비 + 잡비
식비 = 16,000원 × 박 수      (주말 식비는 8,000원 × 주말 일수로 따로)
잡비 = 20,000원 × 일 수
```

- 1박 2일 = 식비 1회 · 잡비 2회 / 2박 3일 = 식비 2회 · 잡비 3회. 항상 식비 횟수 = 잡비 횟수 − 1
- 숙박비 = 매출전표 실결제액 (할인이 반영된 최종 금액). **단 1박 70,000원까지만** 넣는다. 한도 = 70,000원 × 박 수
  - 예: 1박 82,000원 결제 → 70,000원 / 2박 196,000원 결제 → 140,000원 / 1박 64,350원 결제 → 64,350원
  - 한도를 넘은 금액은 엑셀에 넣지 않고, 만든 뒤 "실결제 ○원 중 ○원만 넣음"으로 알린다 (`복명서_생성.py`도 한도를 넘으면 한도까지만 넣는다)
- 자가차량(자차) = 지도 길찾기 화면의 편도 값으로 왕복을 계산한다
  - 교통비 [연료비] = 연료비의 천 원 미만을 버린 값 × 2 (예: 15,388원 → 15,000원 × 2 = 30,000원)
  - 교통비 [하이패스] = 통행료 × 2 (예: 5,800원 × 2 = 11,600원) → spec의 `hipass`
  - 시트 이름 `당일 자가차량` (1박 이상이면 `1박 이상 자가차량`)
- 회사가 부담한 이동수단(회사차·업무차량)은 세부 내역만 쓰고 금액은 0
- 당일(외근 복명)은 잡비가 없다. `misc_amount`는 0으로 넣고 묻지 않는다

## 4. 법인카드 / 개인카드

카드번호 앞 8자리로 가른다. 파일 이름의 표기보다 카드번호가 우선이다.

| 카드번호 앞 8자리 | 구분 | 표기 |
|---|---|---|
| `12345678` (실습용 가상 번호) | 법인카드 | 세부 내역에 `(법인카드 결제)` |
| 그 외 | 개인카드 | 표기 없음 |

- 법인카드 결제도 금액은 넣는다. 표기만 다르다
- 한 칸 안에 법인·개인이 섞이면 줄마다 표기한다
- 애매하면 묻지 않고 카드번호대로 넣은 뒤 "확인 필요"로 알린다

## 5. 세부 내역 쓰는 법

교통비 (금액은 쓰지 않는다)
```
KTX 이용 (법인카드 결제)
1. 서울 -> 동대구
2. 동대구 -> 서울
```

자가차량 (운행 경로 필수)
```
자가차량 이용
1. 페럼타워 -> 동국제강 당진공장
2. 동국제강 당진공장 -> 페럼타워
```

숙박비 (숙소명 + 박 수)
```
대구 OO호텔
1. 1박 2일
```

출장 기간
```
◎ 출장 기간 (2026.10.15 ~ 2026.10.16), 1박2일      ← 1박 이상
◎ 출장 기간 (2026.10.15)                            ← 당일
```

## 6. 엑셀 만들기 — 양식을 깨뜨리지 않는 방법

**양식 xlsx를 openpyxl·pandas 등으로 열어서 다시 저장하지 않는다.** 다시 저장하면 인쇄 설정, 셀 메모, "B. 비용 영수증" 도형이 사라져 결재 양식이 깨진다.

`복명서_생성.py`를 쓴다 (작업실에서는 `09_프로그램 (열지 않아도 됨)` 안, skill에서는 `assets` 안). 이 스크립트는 양식 파일을 열지 않고 zip 안에서 바꿀 칸만 바꾸고, 영수증 이미지를 "B. 비용 영수증" 네모 칸 안에 한 줄에 두 장씩(세 번째부터는 아래 줄) 원래 비율대로 붙인다.

1. 영수증에서 읽은 값으로 `spec.json`을 **영수증 폴더 안에** 쓴다 (UTF-8)
2. 이 폴더(`02_출장복명`)에서 실행한다. Python은 실습 폴더에 들어 있어 따로 설치하지 않는다

```
& ".\09_프로그램 (열지 않아도 됨)\python\python.exe" ".\09_프로그램 (열지 않아도 됨)\복명서_생성.py" "<영수증 폴더>\spec.json"
```

3. 출력된 합계·영수증 장수를 보여 준다

- `09_프로그램 (열지 않아도 됨)\python\python.exe`가 없으면 `python "<복명서_생성.py 경로>" "<영수증 폴더>\spec.json"`
- 스크립트는 표준 라이브러리만 쓴다. pip 설치를 하지 않는다

1박 이상 spec 예시 (형식만 참고. 값은 반드시 영수증에서 읽는다)

```json
{
  "mode": "1박이상",
  "out": "출장 복명_대구_261015.xlsx",
  "sheet_name": "1박 이상 대중교통",
  "period": "◎ 출장 기간 (2026.10.15 ~ 2026.10.16), 1박2일",
  "transport": {"text": "KTX 이용 (법인카드 결제)\n1. 서울 -> 동대구\n2. 동대구 -> 서울", "amount": 87000},
  "hipass": 0,
  "lodging": {"text": "대구 OO호텔\n1. 1박 2일", "amount": 70000},
  "meals": 1, "misc": 2, "weekend_meals": 0,
  "images": ["01_KTX_가는편.png", "02_KTX_오는편.png", "04_숙박_매출전표.jpg", "03_숙박_예약내역.png"]
}
```

- 당일은 `"mode": "당일"`, `lodging`·`meals`·`misc` 대신 `"misc_amount": 0` (당일은 잡비 없음)
- 숙박 영수증이 없으면 `lodging`을 빼면 숙박비 0, 세부 내역 공란
- `images`·`out`은 영수증 폴더 안의 파일 이름 (spec.json이 있는 폴더 기준). `images` 순서 = 붙는 순서. 교통 → 숙박 매출전표 → 숙박 예약내역
- 영수증 이미지는 PNG · JPG. 다른 형식(HEIC 등)이면 PNG로 다시 저장해 달라고 한다
- `out`의 날짜(YYMMDD)는 출장 시작일
- `[양식 불일치]` 오류가 나면 양식 파일이 바뀐 것이다. 양식을 다시 저장하지 말고 사람에게 알린다

스크립트를 실행할 수 없는 환경이면 같은 원칙으로 직접 한다. xlsx를 zip으로 풀고 `xl/worksheets/sheet3.xml`의 금액·횟수 칸 값, `xl/sharedStrings.xml`의 출장 기간·세부 내역 문구, `xl/drawings/drawing3.xml`의 영수증 그림만 바꾼 뒤 다시 zip으로 묶는다. 그 외 파일은 건드리지 않는다.

| 칸 (1박 이상) | 내용 | 칸 (당일) | 내용 |
|---|---|---|---|
| E11 | 교통비 | E9 | 교통비 |
| E12 | 하이패스 | E10 | 하이패스 |
| E13 | 숙박비 | E11 | 잡비 금액 |
| F14 | 식비 횟수 | | |
| F15 | 잡비 횟수 | | |
| F16 | 주말 식비 횟수 | | |
| D11 · D13 · B1 | 교통 · 숙박 세부 내역 · 출장 기간 | D9 · B1 | 교통 세부 내역 · 출장 기간 |

## 7. 기타보고 txt — 전자결재 본문

xlsx는 결재에 첨부하고, 결재 화면 본문에는 기타보고 txt 내용을 붙여넣는다. 그래서 항상 xlsx와 같이 만든다.
파일 이름 = xlsx 이름 끝에 `_기타보고.txt` (예: `출장 복명_포항_261112_기타보고.txt`), xlsx와 같은 영수증 폴더. `복명서_생성.py`가 xlsx 이름에서 만든다.

```
출장 목적 : 
내용 : 
```

- 칸 제목만 둔다. 출장 목적 · 내용은 사람이 채운다. AI가 묻거나 지어내지 않는다
- 메모장·전자결재 편집기에서 줄바꿈이 깨지지 않게 UTF-8 + CRLF로 저장한다 (`복명서_생성.py`가 만든다)

## 8. 만든 뒤

1. 합계·박 수·식비·잡비 횟수를 표로 보여 준다
2. "확인 필요" 항목을 반드시 말한다
   - 영수증이 없는 항목 (숙박 미예약, 회사차 이용 등)
   - 출장 기간이 앞뒤 출장과 겹칠 때 (잡비가 두 번 들어간다)
   - 카드 구분이 애매한 건
   - 숙박비가 1박 70,000원을 넘어 한도까지만 넣은 건 (실결제액과 넣은 금액)
3. 기타보고 txt의 출장 목적 · 내용은 직접 채우라고 알린다
4. 결재 상신은 하지 않는다
