# 프론트엔드 디자인 skill (frontend-design)

> **이 skill은 Anthropic이 만들어 공개한 skill입니다.** 찾아가는 AI교육서비스팀이 만든 것이 아닙니다.
> 원본: [anthropics/skills — frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)
> 라이선스: Apache License 2.0 (`frontend-design/LICENSE.txt`)
> 이 저장소에는 원본을 고치지 않고 그대로 넣었고, 설치 파일(`.bat`)과 이 안내만 덧붙였습니다.

웹 페이지·화면을 만들 때 흔한 템플릿처럼 보이지 않도록 분위기·글꼴·색·배치 방향을 먼저 정하고 디자인하게 하는 skill입니다.
「바로쓰는 HTML공지 스킬 만들기」 강의에서 HTML 공지 디자인을 다듬을 때 함께 썼습니다.

## 다운로드

[frontend-design-skill.zip 받기 (v1)](https://github.com/dkaieduteam/dk-ai-lab/releases/download/frontend-design-v1/frontend-design-skill.zip)

## 받은 뒤 할 일

1. `frontend-design-skill.zip`을 받습니다.
2. 압축을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 클릭 → 속성 → 「차단 해제」를 체크하고 확인을 누릅니다.
3. 압축을 풀고 `프론트엔드디자인_skill` 폴더를 엽니다.

2번을 하지 않으면 `.bat` 파일을 실행할 때 「Windows의 PC 보호」 경고가 뜹니다.

## 준비

- ChatGPT 데스크탑 앱

## 등록 방법

1. `skill 설치.bat`을 더블클릭합니다. `frontend-design` skill이 이 PC의 Codex skills 폴더에 설치됩니다.
2. ChatGPT 앱에서 새 채팅(Ctrl+N)을 열고 입력창에 `$`를 치면 목록에 `Frontend Design`이 보입니다.
3. 지우려면 `skill 지우기.bat`을 실행합니다.

Claude를 쓰면 따로 받지 않아도 됩니다. Claude 앱과 Claude Code에서 Anthropic 공식 skill로 바로 켤 수 있습니다.

## 사용법

1. 결과 파일을 저장할 폴더를 ChatGPT 앱에서 엽니다. 「파일」 → 「폴더 열기」로 고르고 「폴더 신뢰」를 누릅니다.
2. 새 채팅에서 `$`로 `Frontend Design`을 고르고 만들 화면을 요청합니다. 예: 「사내 공지용 HTML 페이지 만들어 줘」.
3. AI가 디자인 방향을 정해 HTML을 만듭니다. 마음에 들지 않으면 분위기나 색을 바꿔 달라고 다시 요청합니다.
