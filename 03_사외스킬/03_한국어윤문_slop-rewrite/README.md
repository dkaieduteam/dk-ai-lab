이 저장소에는 파일을 따로 두지 않습니다. 원본 주소에서 바로 받으면 만든 사람이 고친 최신 내용을 받을 수 있습니다.

## 어떤 skill인가요

AI가 쓴 한국어 초안에서 AI 티를 덜어 내고, 글의 종류와 문체, 쓰는 사람의 취향에 맞게 다시 쓰는 skill입니다. 「솔직히 말씀드릴게요」, 「어렵게 들리시나요?」 같은 상투적인 앞말이나 뻔한 비유를 걷어 내고, 핵심이 곧장 전달되는 문장으로 고칩니다.

- 만든 목적: AI가 쓴 글을 사람이 쓴 것처럼 자연스럽고 핵심이 잘 보이게 다듬는 것
- 잘 맞는 일: 공지·메일·보고서·교안·블로그 글 윤문, 개조식 보고서 정리, 「고치지 말고 검토만」 받기
- 세 층으로 고칩니다.
  - **원칙**: 누구에게나 AI 티로 읽히는 표현 규칙
  - **문체 가이드**: 업무·토스·장피엠·개조식 가운데 고르거나, 내가 쓴 글로 내 가이드를 만듭니다
  - **내 취향**: 결과물에 「나라면 이렇게 쓴다」를 달면 다음 윤문부터 반영합니다
- 지키는 것: 원문에 없는 숫자·이름·인용을 보태지 않고, 뜻을 뒤집지 않습니다. 원본 파일은 그대로 두고 결과를 `<원본명>.taste.<확장자>` 파일로 따로 저장합니다.
- 우리 팀에서는: 교안·공지·메일 같은 팀 문서를 다듬을 때 이 skill을 씁니다.

## 설치 방법

Python 3이 필요합니다. 하나의 skill 파일이 아니라 규칙·문체 가이드·검사기가 함께 든 폴더라서, 폴더째 받아 그 폴더를 AI 앱에서 엽니다.

1. [slop-rewrite-main.zip](https://github.com/byungjunjang/slop-rewrite/archive/refs/heads/main.zip)을 받아 압축을 풉니다.
   (원본 주소에서 Code → Download ZIP을 눌러도 같습니다.)
2. 압축을 푼 `slop-rewrite-main` 폴더를 AI 앱에서 엽니다.
   - **ChatGPT 데스크탑 앱**: 「파일」 → 「폴더 열기」로 고르고 「폴더 신뢰」를 누릅니다.
   - **Claude Code**: 그 폴더에서 Claude Code를 실행합니다.
3. 새 채팅에서 `$`를 쳐서 `slop-rewrite`가 보이면 됩니다. 보이지 않으면 앱을 다시 시작합니다.

다른 폴더에서도 부르고 싶다면 원본 README의 「다른 프로젝트에서 부르기」 절을 따릅니다.

## 사용법

1. 다듬을 글을 `.md`나 `.txt` 파일로 위 폴더 안에 넣습니다.
2. 자연어로 요청합니다. 예:
   - 「이 파일 윤문해줘」
   - 「토스 문체로 다듬어줘」
   - 「이 보고서는 고치지 말고 검토만 해줘」
3. 원본 옆에 생긴 윤문 파일(`.taste.md`)과 작업 기록(`.taste-notes.md`)을 확인합니다. 작업 기록에 무엇을 고치고 뺐는지가 남습니다.

## 주의할 점

- 회사 자료가 든 글을 윤문하면 그 내용이 AI 앱으로 전달됩니다. 회사가 허용한 AI 도구와 계정에서만 씁니다.
- 내 취향을 쌓는 `taste/` 폴더에는 내가 단 코멘트와 원문 인용이 저장됩니다. 이 폴더를 공개 저장소나 개인 클라우드에 올리지 않습니다.
- 숫자·부정·조건이 바뀌었는지는 사람이 원문과 결과를 대조해 한 번 더 확인합니다.
