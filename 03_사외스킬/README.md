# 03_사외스킬

다른 회사나 개발자가 만들어 공개한 skill과 skill 관련 도구 가운데 강의에서 함께 쓰거나 추천하는 것입니다.

> **⚠ 사외 skill을 받기 전에 먼저 [SkillSpector](01_스킬보안점검_SkillSpector)로 보안 점검을 하시길 권합니다.**
> 공개된 skill 가운데 일부에는 내 파일·계정 정보를 밖으로 보내거나 AI의 안전 규칙을 무시하게 만드는 내용이 숨어 있습니다. 이 폴더에 있는 skill도, 다른 곳에서 찾은 skill도 설치하기 전에 한 번 검사합니다.

이 폴더에는 skill 파일을 올리지 않습니다. 각 폴더의 README에 만든 곳, 만든 목적, 원본 주소, 설치 방법만 적습니다. 원본 주소에서 바로 설치하면 만든 곳이 고친 최신 내용을 받을 수 있습니다.
