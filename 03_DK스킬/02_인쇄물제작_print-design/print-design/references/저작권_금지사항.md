# 저작권 금지사항

> 이 skill이 지켜야 하는 선이다. 사용자가 요청해도 넘지 않는다. 대신 "참고해서 새로 만드는" 방법을 제안한다.
>
> **기준: 비슷하게는 된다. 똑같이는 안 된다.** 레퍼런스와 분위기·구성·스타일이 비슷한 새 디자인은 만든다. 레퍼런스를 그대로 옮긴 복제본은 만들지 않는다.

## 하지 않는 것

1. **레퍼런스를 똑같이 복제하지 않는다.** 사용자가 올린 미리캔버스·망고보드·캔바 템플릿, 핀터레스트 이미지의 일러스트·사진·문구를 그대로 옮기거나, 구도·배치·요소를 하나하나 맞춰 따라 그리지 않는다. "이거랑 똑같이", "그대로 따라 해 줘"는 받지 않는다. "이런 느낌으로", "비슷한 분위기로"는 받는다.
2. **레퍼런스 이미지 자체를 결과물에 쓰지 않는다.** 업로드된 이미지를 잘라 붙이거나, 그 이미지를 고쳐서(편집 원본으로) 배경을 만들지 않는다. 레퍼런스는 분위기·구성을 참고하는 데 쓰고, 그림은 새로 만든다.
3. **다른 회사의 로고·상표·캐릭터를 그리지 않는다.** 사용자가 직접 올린 자사 로고 파일만 쓴다. 로고를 이미지 모델로 다시 그리지 않는다 — 원본 파일을 그대로 얹는다.
4. **실존 인물 사진·연예인·작가 화풍을 흉내 내지 않는다.** "○○ 작가 스타일"은 색·분위기 같은 일반 특징으로 바꿔 받는다.
5. **글꼴은 눈누 무료 글꼴 중 「인쇄 — 사용 가능」인 것만 쓴다**(`글꼴_규칙.md`). 사용자가 고르거나 AI가 디자인에 맞춰 고른다. 쓴 글꼴은 이름·눈누 링크를 결과물마다 알려, **사람이 인쇄 사용 조건을 한 번 더 확인**하게 한다. 출처를 알 수 없는 글꼴 파일은 쓰지 않는다.

## 비슷하게 해도 되는 것 / 똑같이 하면 안 되는 것

| 비슷하게 해도 되는 것 | 똑같이 하면 안 되는 것 |
|---|---|
| 정보 순서 (행사명 → 일시 → 장소) | 원본의 문구·카피를 그대로 |
| 색 조합·분위기 (남색 + 금색 포인트) | 원본의 일러스트·사진·패턴을 그대로 |
| 전체 구성 (위에 제목, 가운데 여백, 아래 정보 띠) | 원본의 구도·배치·요소 크기를 하나하나 맞춘 복제 |
| 장식 스타일 (금박 선, 수채 번짐, 기하학 도형) | 원본의 로고·캐릭터·고유 장식을 그대로 |
| 글자 위주 / 사진 위주, 여백 많이 쓰기 | 원본을 캡처해 글자만 바꿔 쓰기 |

**판단이 애매할 때**: 나란히 놓고 봤을 때 "같은 디자인에 글자만 바꾼 것"으로 보이면 똑같이 한 것이다. 그렇게 보이면 구성 요소 2가지 이상(색·장식·배치 등)을 바꿔 새로 만든다.

## 레퍼런스 사이트 이용 범위

- **미리캔버스·망고보드·캔바**의 템플릿과 요소는 **각 서비스 안에서, 그 서비스의 라이선스 범위로** 쓰는 것이다. 템플릿을 캡처해 다른 도구로 옮겨 재현하는 것은 범위 밖이다. 망고보드는 템플릿·요소를 재편집 가능한 형태로 판매·납품하는 것도 금지한다.
- **핀터레스트**의 이미지는 각 원작자의 저작물이다. 핀터레스트에 올라와 있다고 사용 권한이 생기지 않는다. 분위기·구성을 참고하는 데는 쓰고, 이미지 자체를 가져다 쓰지 않는다.

## 사용자가 "똑같이" 요청할 때 답하는 방식

> 올려 주신 자료를 똑같이 옮기면 원작자의 저작권을 침해할 수 있어 그대로 복제하지는 않습니다.
> 대신 [색 조합 / 구성 / 장식 스타일]이 비슷한 새 시안으로 만들겠습니다.
