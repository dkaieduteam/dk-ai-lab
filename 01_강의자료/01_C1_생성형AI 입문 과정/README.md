# C1_생성형AI 입문 과정

C1 생성형AI 입문 과정 실습 자료입니다. 이미지에서 표·텍스트 뽑기, 회의 메모 정리, 생산일보 CSV 정제·요약(VBA) 실습에 씁니다.
실습 데이터는 실습용 자료입니다.

## 다운로드

[c1-genai-course.zip 받기 (v2)](https://github.com/dkaieduteam/dk-ai-lab/releases/download/c1-genai-v2/c1-genai-course.zip)

## 받은 뒤 할 일

1. `c1-genai-course.zip`을 받습니다.
2. 압축을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 클릭 → 속성 → 「차단 해제」를 체크하고 확인을 누릅니다.
3. 압축을 풀고 `C1_생성형AI 입문 과정` 폴더를 엽니다.

## 사용법

| 파일 | 쓰는 실습 |
|---|---|
| `B1 사진에서 표_텍스트 추출_샘플.jpg` | 사진 속 표를 텍스트·표로 옮기기 |
| `C2 회의 메모_샘플.png` | 손글씨 회의 메모를 정리본으로 만들기 |
| `국민연금 공지.png` | 이미지 공지를 읽고 요약하기 |
| `생산일보_오류포함_실습2.csv` | 실습2 · 오류가 섞인 생산일보 정제 |
| `생산일보_정제본_실습3.csv` | 실습3 · 정제된 생산일보로 요약 리포트 만들기 |
| `실습3_정답VBA_붙여넣기용.txt` | 실습3 정답 VBA (파일 맨 위에 붙여넣는 법이 있습니다) |
