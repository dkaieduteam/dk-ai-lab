# DESIGN.md — 피클(pickle.com) 스타일 참고 기준

- 출처: https://pickle.com/ko 공개 CSS(`/assets/main-*.css`)에서 2026-11-09 추출한 값
- 차용 범위: 색·여백·모서리·그림자·글자 크기 같은 **시각 언어만** 빌린다. Pickle 로고·워드마크·폰트 파일·이미지·문구는 쓰지 않는다
- 해당 회사의 공식 디자인 시스템이 아니다

## 1. 인상

흰 바탕에 검정 하나. 색으로 꾸미지 않고 **여백, 큰 둥근 모서리, 부드러운 그림자, 반투명 유리(blur)** 로 층을 만든다. 버튼·태그는 전부 알약(pill) 모양. 글자는 자간을 살짝 좁혀 단단하게 보인다.

## 2. 색

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ink` | `#000` | 본문·제목·주 버튼 배경 |
| `--paper` | `#fff` | 바탕·카드 |
| `--paper-2` | `#fafafa` | 구획 바탕 |
| `--paper-3` | `#f3f3f3` | 칩·입력 바탕 |
| `--line` | `#e8e8ed` / `#00000014` | 구분선·테두리 |
| `--muted` | `#00000080` (50%) | 보조 문장·캡션 |
| `--glass` | `#ffffffc7` + `blur(14.6px)` | 상단 바 |
| `--glass-pill` | `#ffffff57` + `blur(12px) saturate(1.7)` | 사진 위에 얹는 알약 |
| 다크 | `#2c2c2e` / `#3a3a3c` | 다크 모드 카드·테두리 |

강조색은 두지 않는다. 상태 표시(성공·실패)가 꼭 필요할 때만 작은 점 하나에 채도 낮은 색을 쓴다.

## 3. 글자

- 서체: `-apple-system, BlinkMacSystemFont, "SF Pro Display", "Apple SD Gothic Neo", "Pretendard", "Malgun Gothic", sans-serif` (원 사이트의 시스템 폰트 스택 · 라이선스 폰트는 쓰지 않음)
- 굵기는 400 / 510 / 566 / 590 (가변 굵기 느낌, 700 이상 안 씀)

| 역할 | 크기 / 굵기 / 줄간 / 자간 | 모바일 |
|---|---|---|
| 히어로 제목 | 44px / 590 / 1.4 / -0.44px | 28px / -0.28px |
| 섹션 제목 | 24px / 566 / 1.4 / -0.24px | 22px |
| 메뉴·라벨 | 18px / 510 / 1.2 / -0.36px | 16px |
| 본문 | 16px / 400 / 1.45 / -0.16px, 투명도 50%로 보조 | 16px |
| 캡션 | 14px / 400 / 1.4 / -0.14px | 13px |

## 4. 모양

| 요소 | 값 |
|---|---|
| 알약 버튼 | 높이 48px(모바일 44) · 좌우 18px · `border-radius: 90px` · 검정 바탕 흰 글자 · 17px/510 |
| 유리 알약 | 위 `--glass-pill` + `1px solid #00000014` · hover 시 `0 4px 14px #0000001a` + 안쪽 하이라이트 |
| 카드 패널 | 흰 바탕 · `border-radius: 35px` · 안쪽 여백 38px 30px · 큰 부드러운 그림자 |
| 드롭다운·작은 카드 | `border-radius: 18px` · 그림자 `0 1px 24px #0000001f` |
| 목록 항목 | 높이 40px · `border-radius: 12px` |
| 큰 흰 구획 | 아래쪽만 둥글게 `0 0 60px 60px`(모바일 32px) · 겹겹 그림자 `0 26px 57px #00000021, 0 105px 105px #0000001f` |
| 상단 바 | 높이 77px(모바일 68px) · 유리 바탕 · 고정 |

## 5. 움직임

- 짧고 조용하게: 색·투명도 0.1~0.24s, 위치 0.32s `cubic-bezier(.32,.72,0,1)`
- 누를 때 80ms 안에 반응. 화려한 등장 애니메이션은 쓰지 않는다
