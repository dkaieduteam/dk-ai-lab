# 특별기본_바로쓰는 HTML 공지 스킬 만들기

특별기본 「바로쓰는 HTML 공지 스킬 만들기」 실습 자료입니다. IRIS 공지 HTML을 만드는 skill을 직접 만들고, 디자인 공지를 만들어 봅니다.
실습 데이터는 실습용 자료입니다.

## 다운로드

[html-notice-course.zip 받기 (v2)](https://github.com/dkaieduteam/dk-ai-lab/releases/download/html-notice-v2/html-notice-course.zip)

## 받은 뒤 할 일

1. `html-notice-course.zip`을 받습니다.
2. 압축을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 클릭 → 속성 → 「차단 해제」를 체크하고 확인을 누릅니다.
3. 압축을 풀고 `특별기본_바로쓰는 HTML 공지 스킬 만들기` 폴더를 엽니다.

## 사용법

| 폴더 | 들어 있는 것 |
|---|---|
| `실습01_공지스킬만들기` | IRIS 공지 HTML 작성 규칙, 그룹사 CI 로고(svg), 공지 템플릿 예시, 공지용 이미지(zip), `AGENTS.md` |
| `실습02_디자인공지만들기` | IRIS 공지 HTML 작성 규칙, 디자인 레퍼런스 이미지, 디자인시스템 예시(`DESIGN.md` 3종), frontend-design skill(zip), `AGENTS.md` |

실습 폴더를 AI 도구(ChatGPT 앱·Claude 등)에서 작업 폴더로 열고 진행합니다. `AGENTS.md`가 AI에게 작성 규칙 문서를 먼저 읽도록 알려 줍니다.
