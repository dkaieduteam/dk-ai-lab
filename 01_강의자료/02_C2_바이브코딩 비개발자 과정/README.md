# C2_바이브코딩 비개발자 과정

C2 바이브코딩 비개발자 과정 실습 자료입니다. 코딩 없이 AI에게 단계별 프롬프트로 요청해 엑셀 자동화 프로그램을 만듭니다.
실습 데이터는 실습용 자료입니다.

## 다운로드

[c2-vibecoding-course.zip 받기 (v1)](https://github.com/dkaieduteam/dk-ai-lab/releases/download/c2-vibecoding-v1/c2-vibecoding-course.zip)

## 받은 뒤 할 일

1. `c2-vibecoding-course.zip`을 받습니다.
2. 압축을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 클릭 → 속성 → 「차단 해제」를 체크하고 확인을 누릅니다.
3. 압축을 풀고 `C2_바이브코딩 비개발자 과정` 폴더를 엽니다.

## 사용법

| 폴더 | 들어 있는 것 |
|---|---|
| `[예제01]  매일 자동으로 생성되는 엑셀 보고서` | 지점별 매출 엑셀 3개 + 1·2단계 프롬프트 |
| `[예제02]  엑셀 업로드로, 자동 생성되는 대시보드 시스템` | 팀별 영업실적 엑셀 3개 + 1·2·3단계 프롬프트 |

각 예제 폴더의 `1단계 프롬프트.txt`부터 차례로 AI에게 붙여넣습니다. 프롬프트 안의 `[내 폴더 경로]`는 내 PC의 작업 폴더 경로로 바꿉니다.
