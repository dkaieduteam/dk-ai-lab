
코딩을 전혀 모르는 재무팀 직원이야. 윈도우 노트북을 쓰고, 검은 화면(명령
프롬프트)은 무서워해. 그래서 설명은 클릭으로 따라 할 수 있게 해주고, 전문용어는
쓰지 말아줘.

여러 개의 매출 엑셀을 하나로 합쳐서 "보고용 엑셀"과 "보고요약 워드 문서"를
만들어주는 파이썬 프로그램을 만들어줘. 이번 단계에서는 더블클릭으로 실행되는
배치파일까지 만들고, 한 번 실행해서 잘 되는지 확인하는 것까지 해줘.
(윈도우 자동 실행 등록은 다음 단계에서 할 거니까 지금은 하지 마.)

1) [입력]
- 작업 폴더는 여기야: [내 폴더 경로]
- 그 안의 'original_data' 폴더에 있는 '매출_*.xlsx' 파일을 모두 자동으로
  찾아 읽어줘.
- 각 파일의 시트 이름은 '매출원본'이고,
  컬럼은 일자, 거래처, 품목, 수량, 단가, 금액, 결제수단, 담당자 야.
- 파일이 몇 개든 자동으로 처리되게 해줘(나중에 지점이 늘어날 수 있어).

2) [데이터 정리]
- 모든 파일을 위아래로 이어붙여 하나의 표로 만들고, 어느 지점 파일에서
  왔는지 알 수 있게 '지점' 컬럼을 추가해줘(파일명에서 지점 이름을 뽑아서).
- 금액이 비어있거나 숫자가 아닌 행은 제외하고, 제외한 건수를 알려줘.

3) [집계]
- 지점별 총매출, 품목별 총매출, 일자별 총매출을 각각 계산해줘.

4) [결과물]
4-1) 보고용 엑셀 : 현재 폴더 내 'result' 폴더에 만들어줘. 아래 시트를 넣어줘.
   · '원본통합' : 정리된 전체 데이터
   · '집계_지점별', '집계_품목별', '집계_일자별' : 각 집계표
   · '보고요약' : 총매출, 총건수, 지점 수 같은 핵심 숫자를 위에 크게 보여주고,
                  그 아래에 '지점별 매출 막대그래프'와 '일자별 매출 
                  꺾은선그래프'를 넣어줘.
   - 위 두 차트는 워드에서 그림으로 쓸 수 있게 PNG 파일로도 저장해줘
     (예: 차트_지점별.png, 차트_일자별.png).
   - 표에는 제목줄 색 채우기, 천단위 콤마, 테두리 같은 기본 스타일을 적용해줘.
   - 실행이 잘 됐는지/실패했는지 기록이 남는 'log' 텍스트 파일을 만들어줘
     (언제 실행됐고 성공/실패인지, 성공이면 '읽은 파일 수, 합친 행 수,
      제외한 행 수, 총매출 합계' 추가).

4-2) 보고용 워드문서 : 같은 'result' 폴더에 만들어줘.
   - 맨 위에 제목 '(연월) 월간 매출 보고서'와 생성 날짜를 넣어줘.
     연월은 데이터의 일자에서 자동으로 알아내줘.
   - '핵심 요약' 단락 : 총매출, 총건수, 지점 수를 문장으로 정리해줘.
   - '지점별 매출' 표와 '품목별 매출' 표를 넣고, 4-1)에서 저장한
      차트 이미지(PNG)를 그림으로 함께 넣어줘. 이미지 파일이 없으면
      차트를 새로 그려서 넣어줘.
   - 제목은 굵게, 표는 줄 간격 있게 깔끔하게 해줘.
   - 'log' 파일에 워드 생성 성공/실패와, 성공이면 생성한 파일명을 추가해줘.

4-3) 실행될 때마다 결과 파일명 뒤에 날짜와 시간을 년월일시분초로 붙여줘
   (예: 통합보고서_20260629130000.xlsx, 월간매출보고서_20260629130000.docx).
   → 이전 결과가 덮어써지지 않게.

5) [더블클릭 실행용 배치파일]
- 더블클릭하면 위 프로그램이 한 번에 실행되는 'run_daily.bat' 파일을 만들어줘.
  (다음 단계에서 이 파일을 윈도우 자동 실행에 등록할 거야)
- 조건:
  · 어느 위치에서 실행돼도 안전하게, 자기 폴더로 먼저 이동하게 해줘.
  · ★ 파이썬 실행파일의 전체 경로를 직접 찾아서 넣어줘
    (나중에 자동 실행할 때 python을 못 찾는 일 방지).
    못 찾았을 때만 그냥 'python'을 쓰도록 예비 처리도 해줘.
  · 성공/실패를 'result' 폴더의 '자동실행기록.txt'에 한 줄씩 쌓아줘.
  · ★ 더블클릭했을 때 창이 바로 닫히지 않게 잠깐(15초)만 기다리게 해줘.
    단, 'pause' 말고 'timeout'을 써줘 (자동 실행 때 창이 멈춰 있으면 안 되니까).
  · ★ bat 파일 안에 한글이 있으니, 한글 윈도우 명령창에서 글자가 깨지지 않는
    인코딩(CP949/ANSI)으로 저장해줘.

6) [확인 / 마무리]
- 필요한 프로그램(파이썬, 필요한 패키지)과 설치 방법을 자세히 알려주고,
  ★ 설치까지 직접 해줘. 이미 설치돼 있으면 확인만 하고 알려줘.
- ★ 차트에 한글이 깨지지 않게 한글 폰트(맑은 고딕 등)를 반드시 설정해줘.
- ★ 다 만들었으면 한 번 실행해서, 결과가 제대로 나왔는지 너가 직접 확인해줘.
  (엑셀 시트 구성, 핵심 숫자, 차트 한글 깨짐 여부까지 확인해서 보여줘)
- 실행 방법을 클릭 순서대로 쉽게 알려주고,
  그 내용을 '1단계가이드' 파일로 저장해줘.
- 마지막에 만들어진 파일 목록과 실행 결과 요약(총매출, 총건수, 제외 건수)을
  정리해줘.
