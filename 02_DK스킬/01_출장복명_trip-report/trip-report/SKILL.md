# 출장복명

1. 먼저 [출장정산_규칙.md](출장정산_규칙.md)를 읽고 적용한다. 사용자가 지정한 영수증 이미지를 각각 직접 확인하고, 파일명보다 이미지 내용을 우선한다.
2. 날짜, 종류, 구간 또는 숙소, 금액, 카드번호 앞 8자리를 표로 보여 주고 사용자 확인을 받는다. 숙박 기간은 예약 내역으로, 실결제액은 매출전표 합계로 확인한다.
3. 자료나 사용자의 답변에 없는 값은 만들어 내지 말고 질문한다. 부서, 이름, 출장 제목·목적, 필요한 출장 기간·금액·카드 구분과 당일 잡비 등 생성에 필요한 값이 불명확하면 확인한 뒤 진행한다. 영수증이 없는 항목도 확인한다. 규칙으로 계산할 수 있는 횟수와 금액은 계산한다.
4. 사용자가 생성에 동의하고 필요한 정보가 확인되면 작업 폴더에 UTF-8 `spec.json`을 작성한다. 규칙의 예시와 스키마를 따르며 `images`와 `out`의 상대 경로는 spec 파일이 있는 폴더를 기준으로 한다. 기존 파일을 덮어쓸 상황이면 먼저 확인한다.
5. `python <이 스킬의 절대경로>/assets/복명서_생성.py <spec.json의 절대경로>`를 실행한다. Python과 Pillow가 필요하다. 생성기는 자신의 폴더에서 양식을 읽으므로 양식과 스크립트를 함께 둔다. 양식 xlsx를 열어 다시 저장하지 않는다. `[양식 불일치]`가 발생하면 중단하고 사용자에게 알린다.
6. 결과 xlsx와 기타보고 txt, 합계, 박 수, 식비·잡비 횟수, 영수증 장수를 확인하고 링크와 함께 보고한다. 누락 영수증, 기간 중복 가능성, 카드 구분 등 확인할 사항을 알린다. 전자결재 상신은 하지 않는다.
