# 재경실 작업실

재경실 워크샵(품의서·출장복명)에서 쓰는 실습 세트입니다.

## 다운로드

[jaegyeong-workroom.zip 받기 (v1)](https://github.com/dkaieduteam/dk-ai-lab/releases/download/jaegyeong-v1/jaegyeong-workroom.zip)

## 받은 뒤 할 일

1. `jaegyeong-workroom.zip`을 받습니다.
2. 압축을 풀기 전에 zip 파일을 마우스 오른쪽 버튼으로 클릭 → 속성 → 「차단 해제」를 체크하고 확인을 누릅니다.
3. 압축을 풀고 `재경실_작업실` 폴더를 엽니다.

2번을 하지 않으면 `.bat` 파일을 실행할 때 「Windows의 PC 보호」 경고가 뜹니다.

## 사용법

ChatGPT 데스크탑 앱에서 진행합니다. 앱에서 「파일」 → 「폴더 열기」로 폴더를 고르고 「폴더 신뢰」를 누르면 그 폴더에서 일합니다. 폴더마다 `AGENTS.md`가 있어 AI가 그 폴더의 규칙을 먼저 읽습니다.

### 01_품의서 — 품의서를 전자결재 HTML로 바꾸기

1. `01_품의서 넣기` 폴더에 품의서 파일을 넣습니다 (txt · docx · pptx · xlsx · pdf · hwpx).
2. `품의서 만들기.bat`을 더블클릭하면 브라우저에 결과 페이지가 열립니다.
3. 서식이 맞으면 「HTML 코드 복사」를 눌러 전자결재 본문 편집기의 HTML 편집 화면에 붙여 넣습니다.
4. 서식이 다르면 ChatGPT 앱에서 `09_프로그램 (열지 않아도 됨)` 안의 `01_품의서 AI작업실` 폴더를 열고, 건 번호와 줄 번호로 고칠 곳을 말합니다. (예: 건0003 9번 줄 바로 아래에 표가 들어가야 해. 이것만 고쳐 줘.)
5. AI가 고쳤다고 하면 `품의서 만들기.bat`을 다시 실행합니다.
6. 새 버전이 마음에 들지 않으면 `이전 버전으로.bat`을 실행합니다.

품의 내용은 AI에게 주지 않습니다. HTML 변환은 내 PC의 프로그램이 하고, AI는 그 프로그램만 고칩니다.
자세한 순서는 `01_품의서/사용법.md`에 있습니다. 실습용 품의 샘플 PPTX는 포함하지 않으므로 본인 품의서나 가상 문서로 진행합니다.

### 02_출장복명 — 영수증으로 복명서 만들기

1. ChatGPT 앱에서 `02_출장복명` 폴더를 엽니다.
2. 영수증 폴더(예: `01_영수증_포항1박`)를 지정해 출장복명을 만들어 달라고 요청합니다.
3. AI가 `출장정산_규칙.md`를 따라 영수증을 읽고 회사 양식 xlsx로 복명서를 만듭니다. 1박 이상은 출장 복명, 당일은 외근 복명입니다.

영수증 폴더 4개는 실습용 가상 영수증입니다.

### 03_완성 skill — 출장복명 skill 설치

1. `skill 설치.bat`을 더블클릭하면 `trip-report` skill이 이 PC의 Codex skills 폴더에 설치됩니다.
2. 설치 후에는 어느 폴더에서든 "출장복명 만들어 줘"로 같은 작업을 할 수 있습니다.
3. 지우려면 `skill 지우기.bat`을 실행합니다.
