# IRIS 공지 HTML

IRIS 에디터에 통째로 붙여넣을 단일 `.html` 공지를 만든다. 디자인(색·레이아웃·분위기)은 자유롭게 정하고, IRIS에서 깨지지 않게 하는 기술 조건은 [IRIS 공지 HTML 작성규칙](references/IRIS_공지_HTML_작성규칙.md)을 예외 없이 지킨다.

## 0. 먼저 규칙 문서를 읽는다

작업을 시작하기 전에 `references/IRIS_공지_HTML_작성규칙.md`를 끝까지 읽는다. 내용이 길어 잘려 보이면 §6 「금지 / 허용」과 「최종 체크리스트」를 나눠 다시 읽는다. 기억에 의존하지 않는다.

## 1. 내용 확인

사용자가 준 사실만 쓴다. 날짜·장소·대상·신청 방법·문의처·금액을 지어내지 않는다.

- 공지에 꼭 필요한 정보(제목, 무엇을 알리는지, 대상, 일시·장소 또는 기한, 신청·문의 방법)가 빠졌으면 작성 전에 한 번에 모아 묻는다.
- 사용자가 「일단 양식만」, 「샘플로」라고 하면 묻지 않고 `[일시]`, `[문의처]`처럼 바꿔 넣을 자리를 대괄호로 남긴다.
- 실명·연락처·사번·금액 같은 개인정보와 민감정보는 숨김 요약에 넣지 않는다. 본문에도 사용자가 넣으라고 한 것만 쓴다.
- 이미지·로고 파일을 받았으면 원본은 그대로 두고, 줄인 사본을 base64로 넣는다(규칙 §5). 받지 않은 사진을 임의로 만들어 넣지 않는다.

## 2. 작성

1. 이 공지만 쓰는 짧은 prefix를 정한다(예: `hr1117-`, `safety-`). 모든 클래스·keyframe·SVG `id`에 붙인다.
2. 규칙 §1의 골격대로 쓴다: `<body>` 첫 자식 = 숨김 요약 `<div>`, 그 뒤 `.PREFIX-wrap` 하나에 디자인 본문 전체.
3. 숨김 요약은 공백 제외 500자 이내의 완성 문장으로 쓴다. 무엇을·누구에게·왜·어떻게·문의 채널을 담는다.
4. `<style>` 맨 위에 리셋 보일러플레이트(§2-2), 맨 뒤에 모바일 지면 블록(§3-2)을 둔다.
5. 제목은 `<div role="heading" aria-level="1">`로 쓰고, 구조 margin·`margin:0 auto`·`line-height`에는 `!important`를 붙인다.
6. 링크는 모두 `target="_blank" rel="noopener noreferrer"`. JavaScript·외부 리소스·웹폰트·상대경로 이미지는 쓰지 않는다.
7. 섹션 이름표(20자 이내) 외의 주석은 남기지 않는다.

기존 공지를 고칠 때는 사용자가 바꾸라고 한 부분만 고치고, 나머지 디자인과 문구는 그대로 둔다. 고치는 김에 규칙 위반을 발견하면 해당 선언만 보강하고 무엇을 보강했는지 알린다.

## 3. 붙여넣기 전 점검

결과를 넘기기 전에 규칙의 「최종 체크리스트」를 항목별로 확인한다. 코드나 브라우저를 쓸 수 있으면 직접 센다.

- 본문 텍스트(`document.body.innerText` 또는 태그를 걷어 낸 텍스트)가 한글 요약으로 시작하는가
- `<a>` 수 = `target="_blank"` 수 = `rel="noopener noreferrer"` 수
- `<script>`·`on…=`·`<link>`·`@import`·`@font-face`·`http`로 시작하는 `src` 0건
- 모든 `<img src>`가 `data:`로 시작
- `<h1>`~`<h6>` 0건, prefix 없는 선택자 0건
- 파일 크기 1MB 미만(권장 300KB대)
- 가능하면 규칙 §7 ②의 margin·line-height 강제 주입을 흉내 내고, 컨테이너를 360px로 좁혀 겹침과 넘침이 없는지 본다.

## 4. 전달

- 완성한 `.html` 파일 하나를 저장하고 경로를 알려 준다. 파일명은 `IRIS_<게시범위>_<주제>_<내용>.html` 형식을 권한다(예: `IRIS_사내공지_안전교육_참석안내.html`). 고친 판은 `_v2`처럼 뒤에 붙인다.
- 체크리스트 결과를 짧게 보고한다. 통과한 것, 확인하지 못한 것(예: 실제 IRIS 모바일 화면)을 구분해서 적는다.
- 게시는 사용자가 직접 한다: IRIS 글쓰기 → 에디터의 HTML 편집 화면에 파일 내용을 통째로 붙여넣기 → 미리보기 확인 → 등록. 이 skill은 게시하거나 메일을 보내지 않는다.
