# 인쇄 발주 주의사항

> 결과물을 넘길 때 사용자에게 「발주 전 확인」으로 함께 보여 준다. 해당 품목에 맞는 줄만 고른다.

## 0. 먼저 — 인쇄소 작업 규격을 확인한다

skill이 처음 만드는 파일은 **대표 규격 기준 초안**이다. 인쇄소마다 요구가 다르므로 발주 전에 아래를 인쇄소(주문 페이지의 「작업 가이드」·「파일 접수 안내」)에서 확인하고, 그 값으로 고쳐 최종본을 만든다.

| 확인할 것 | 예 |
|---|---|
| 작업 크기 | 완성 크기 그대로인지, 재단 여백을 더한 크기인지 |
| 재단 여백·안전선 | 1.5mm / 2mm / 3mm, 현수막 여분 유무 |
| 재단선 표시 | 넣어야 하는지 |
| 파일 형식 | PDF / JPG / 1/10 축소 파일 |
| 색상 모드·해상도 | CMYK 접수 기준, 지정 ICC 프로파일(예: Japan Color 2001 Coated), 최소 dpi |

## 1. 파일 형식 — 인쇄소에는 PDF를 넘긴다

| 형식 | 쓰임 | 이유 |
|---|---|---|
| **PDF (인쇄용)** | **인쇄소 발주** | 글자·도형이 벡터라 크게 뽑아도 선명하다. 재단 여백과 크기 정보가 그대로 들어간다. 글꼴이 파일 안에 들어 있어 인쇄소 PC에서 바뀌지 않는다 |
| PNG | 사내 공유·검토, PDF를 받지 않는 인쇄소 | 화질 손실은 없지만 글자도 픽셀이라 확대하면 계단이 보인다 |
| JPG | 메신저·메일 미리보기 | 파일이 가볍다. 압축 때문에 글자 테두리가 번질 수 있다 |

## 2. 색 — 인쇄용 PDF는 CMYK다

- 모니터는 빛(RGB)으로, 인쇄기는 잉크(CMYK)로 색을 낸다. 화면의 **형광·네온색, 아주 밝은 파랑·초록·주황은 인쇄하면 탁해진다.**
- 이 skill의 인쇄용 PDF는 **CMYK**다. 글자·도형은 CMYK 값으로 그리고, 그래픽(투명 PNG)·로고 이미지는 CMYK로 바꿔 넣는다. 화면 공유용 PNG·JPG만 RGB다.
- 인쇄소가 ICC 프로파일(예: Japan Color 2001 Coated)을 지정하면 받아서 그 프로파일로 다시 만든다. 지정이 없으면 기본 변환식으로 만든 것이므로, 발주할 때 **"CMYK 파일입니다. 교정본(시안)으로 색 확인 부탁드립니다"**라고 적는다.
- 화면 미리보기의 색은 실제 인쇄 색과 다르다. 색이 중요하면 교정본을 받는다.
- 회사 로고처럼 색이 정확해야 하는 부분은 **교정쇄(실물 샘플)**로 확인한다.
- 작은 검정 글자는 **K100(먹 1도)**으로 지정했다. 네 가지 잉크를 섞은 검정은 판이 조금만 어긋나도 글자 테두리가 번진다.
- 채도가 높은 진한 색을 넓게 쓰면 잉크가 많이 올라가 **뒷묻음**(다음 장 뒷면에 묻음)이 생길 수 있다.

## 3. 크기·재단

- 발주서의 크기는 **완성 크기**로 적는다. 종이 인쇄물 PDF는 재단 여백만큼 크다(예: 127×178 → 131×182). 현수막급 PDF는 50% 축소 파일, 족자·배너 PDF는 완성 크기 그대로다.
- 재단선 표시(모서리 「자르는 곳」 표시)는 인쇄소가 요구할 때만 넣는다. 현수막·배너에는 넣지 않는다.
- 배경은 재단 여백까지 채우고, 글자·로고는 안전선 안에 둔다. 「확인용_재단선.png」에서 빨간 선 = 재단선, 파란 선 = 안전선.
- 현수막은 열재단·봉미싱·타공 위치를 확인한다. 가장자리 30mm 안에는 글자를 두지 않는다.
- 접는 인쇄물은 접는 선 위에 글자가 지나가지 않게 한다.
- 현수막급은 **50% 축소 파일**로 넘긴다. 축소 파일은 발주서에 **축척**을 적는다(「50% 축소 파일 — 2배 확대 출력」). 인쇄소가 원본 크기·1/10 크기를 요구하면 그 축척으로 다시 만든다.

## 4. 화질

- PDF로 저장해도 **흐린 사진이 선명해지지는 않는다.** 이미지의 실효 해상도가 낮다는 경고가 나오면 미리보기를 100%로 확대해 확인한다.
- 7pt보다 작은 글자, 아주 얇은 글자는 흐리게 나온다.
- 무료 요금제 도구로 만든 파일은 **워터마크**가 그대로 인쇄된다. 이 skill의 결과물에는 워터마크가 없다.

## 5. 발주 사고 예방 — 보내기 전 마지막 확인

|---|---|---|
| 1 | 완성 크기·가로세로·수량 | 재단 여백 포함 크기로 발주해 크기가 어긋남 |
| 2 | 날짜·요일·시간·장소·연락처 | 요일 오기, 지난 연도 날짜 |

| 6 | 납기·배송지·필수 도착일 | 행사 전날 도착 |
| 7 | 사용 글꼴 라이선스 | `_사용글꼴.txt`의 눈누 링크에서 인쇄 사용 가능 여부를 사람이 확인하지 않음 |
