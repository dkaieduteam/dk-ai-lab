# 인쇄물 제작

## ⚠️ 가장 먼저 — 첫 호출 고지 (예외 없음)

이 skill이 이 대화에서 **처음 불렸으면, 무엇을 요청받았든**(「test」, 이름만 호출, 바로 작업 요청, 파일만 첨부, 질문만 한 경우 모두) **첫 최종 답변의 맨 첫 줄부터** 아래 고지를 **한 글자도 바꾸지 않고 통째로** 출력한다. 요약·생략·순서 변경 금지. 고지를 출력한 뒤에 0단계 안내, 1단계 질문, 작업을 이어 간다.

- **고지는 최종 답변 본문에 넣는다.** 작업 중에 잠깐 보이는 진행 메시지·중간 안내(이미지 생성·코드 실행 중 표시되는 글)에 넣지 않는다 — 작업이 끝나면 접히거나 사라져서 사용자에게 남지 않는다.
- 이미지 생성·코드 실행을 거치는 답변이면, 작업을 모두 마친 뒤 **최종 답변의 맨 앞**에 고지를 놓고 그 아래에 결과를 쓴다.
- 진행 메시지에 고지를 썼더라도 **출력한 것으로 치지 않는다.** 최종 답변에 다시 넣는다.
- **이 대화의 최종 답변에 고지가 있었는지 확실하지 않으면 출력한다.** 두 번 나오는 것은 괜찮지만, 빠지는 것은 안 된다.
- 이 대화의 최종 답변에서 이미 출력했으면 다시 보여 주지 않는다(사용자가 다시 보여 달라고 하면 보여 준다).
- 최종 답변을 보내기 직전에 확인한다: 「이 답변 맨 앞, 또는 이 대화의 이전 최종 답변에 [처음 쓰실 때 꼭 확인해 주세요]가 있는가?」 없으면 맨 앞에 붙인다.

```text
[처음 쓰실 때 꼭 확인해 주세요]

⚖️ 저작권
1. 레퍼런스는 비슷하게는 괜찮지만, 똑같이는 안 됩니다. 문구·그림·사진을 그대로 옮기거나
   캡처해서 글자만 바꾸는 방식은 쓰지 않습니다.
2. 눈누 무료 글꼴도 제작사마다 조건이 다릅니다. 결과와 함께 알려 드리는 [사용 글꼴]의
   링크에서 「인쇄 — 사용 가능」인지 직접 확인해 주세요.
3. 로고는 회사 원본 파일만 씁니다. 다른 회사의 로고·캐릭터, 실존 인물 사진은 넣지 않습니다.
4. AI로 만든 배경은 다른 작품과 우연히 닮을 수 있습니다. 특정 작품이 떠오를 만큼 비슷하면
   다시 만들어 달라고 해 주세요.

🖨️ 인쇄
5. 만들어 드리는 파일은 초안입니다. 발주할 인쇄소의 작업 규격(크기·재단 여백·파일 형식)을
   확인한 뒤 최종본으로 고쳐 주세요.
6. 인쇄용 PDF는 CMYK로 만들어 드립니다. 다만 화면에 보이는 색과 실제 인쇄 색은 다르니,
   인쇄소에 교정본(시안 출력)으로 색을 확인해 주세요. 인쇄소 ICC 프로파일이 있으면 주시면 맞춰 드립니다.
7. 날짜·요일·시간·장소·이름은 AI가 정리한 문구라도 직접 한 번 더 확인해 주세요.

🔒 정보 보호
8. 고객사명·참석자 명단·연락처는 시안 단계에서는 ○○주식회사·홍길동 같은 더미로 쓰고,
   최종본에서만 실제 내용으로 바꿔 주세요.
```

---

바탕은 CMYK 벡터(단색·그라데이션)로 깔고, 이미지 모델로 만든 **투명 배경 PNG 그래픽**과 벡터 글자·로고·도형을 층으로 얹어 인쇄용 파일을 만든다.
**인쇄물이므로 CMYK 기준으로 작업한다.** 글자·도형·배경색은 처음부터 CMYK 값으로 정하고, 이미지 모델이 만든 그래픽과 로고(RGB)는 스크립트가 CMYK로 바꿔 넣는다(투명한 부분은 그대로 투명). 인쇄용 PDF에는 RGB 색이 들어가지 않는다(화면 공유용 PNG·JPG만 RGB).
**이 skill의 결과물은 초안이다.** 규격표의 크기·재단 여백·안전선은 일반적인 대표값일 뿐이고, 실제 발주할 인쇄소의 요구사항(작업 크기·재단 여백·파일 형식·색상 모드·해상도)을 확인한 뒤 그 값으로 고쳐 최종본을 만든다.
**이미지 모델에는 글자를 그리게 하지 않는다** — 글자가 깨지고, 확대하면 흐려지기 때문이다.

```text
바탕(CMYK 벡터)  +  그래픽(투명 PNG, 글자 없음)  +  글자·로고·도형(벡터)  →  PDF(인쇄용)  (+ 종이 인쇄물은 PNG · JPG)
```

함께 들어 있는 파일

| 파일 | 언제 읽나 |
|---|---|
| `references/규격표.md` | 1단계 — 크기·재단 여백·해상도를 정할 때 |
| `references/저작권_금지사항.md` | 2단계 — 레퍼런스를 받았을 때, 재현 요청을 받았을 때 |
| `references/글꼴_규칙.md` | 1·2단계 — 글꼴을 정하고 받을 때 (사용자 선택 또는 AI 선택) |
| `references/인쇄발주_주의사항.md` | 6단계 — 결과를 넘길 때 |
| `scripts/fetch_font.py` | 2단계 — 눈누에서 글꼴 찾기·인쇄 사용 가능 확인·파일 받기 |
| `scripts/prep_graphic.py` | 3단계 — 그래픽 바탕 지우기·벡터 변환 또는 인쇄 해상도로 키우기 |
| `scripts/build_print.py` | 4단계 — 파일 조립 |

## 0단계 · 요청 없이 불렸을 때

skill 이름만 부르거나 「test」, 「시작」처럼 **무엇을 만들지 정보가 없으면** 「호출됐다」고만 답하고 끝내지 않는다. 바로 아래처럼 안내하고 1단계 질문을 시작한다.

```text
인쇄물 제작을 시작하겠습니다. 아래를 알려 주세요(아는 것만 적으셔도 됩니다).

1. 품목 — 현수막 / 초청장 / 감사장 / 포스터 / 배너 등
2. 크기 — 모르시면 대표 규격을 추천해 드립니다
3. 들어갈 문구 — 행사명, 일시, 장소, 주최 등 (고객사명·이름은 더미로 써 주셔도 됩니다)
4. 글꼴 — 눈누에서 고른 글꼴의 페이지 주소 (없으면 디자인에 어울리는 눈누 무료 글꼴을 골라 드립니다)
5. 로고 파일 · 레퍼런스 이미지 (있으면)

바로 써 보시려면 「예시로 현수막 하나 만들어 줘」라고 하셔도 됩니다.
```

「예시로 만들어 달라」고 하면 더미 문구(`2027 고객 초청 세미나` 등)와 대표 규격으로 진행한다. 글꼴은 AI가 눈누에서 골라 진행한다(2단계).

## 1단계 · 무엇을 만들지 확인한다

아래를 사용자에게 확인한다. 이미 말한 것은 다시 묻지 않는다. 한 번에 묻는다.

1. **품목** — 현수막·초청장·감사장 등
2. **크기** — `references/규격표.md`에서 대표 규격을 2~3개 보여 주고 고르게 한다. 사용자가 크기를 직접 주거나 인쇄소 규격이 있으면 그것을 쓴다.
3. **들어갈 문구** — 행사명, 일시, 장소, 주최, 문의처 등
4. **로고 파일** — 있으면 받는다(PNG는 가로 1000px 이상, 투명 배경 권장). 없으면 로고 자리를 비운다.
5. **레퍼런스(선택)** — 사용자가 직접 찾은 이미지·캡처. 없어도 된다.
6. **글꼴(선택)** — 후보는 **눈누 무료 글꼴 전체**다. 사용자가 고른 글꼴이 있으면 그 **눈누 페이지 링크**(+ 굵기)를 받는다. 없으면 묻느라 멈추지 말고 2단계에서 AI가 디자인에 어울리는 글꼴을 고른다. 글꼴 파일은 skill이 받아 온다 — 첨부를 먼저 요청하지 않는다.

**문구에 고객사명·참석자 이름·연락처가 있으면** 시안 단계에서는 `○○주식회사`, `홍길동` 같은 더미로 바꿔 진행하자고 제안한다. 최종본에서 실제 내용으로 바꾼다.

## 2단계 · 방향을 정하고 글꼴을 정한다

`references/저작권_금지사항.md`, `references/글꼴_규칙.md`를 먼저 읽는다.

**레퍼런스가 있을 때**

1. 레퍼런스에서 가져갈 특징을 말로 정리한다 — 정보 순서, 색 조합, 전체 구성, 장식 스타일, 여백 방식.
2. 사용자에게 정리한 특징을 보여 주고, 어떤 것을 가져갈지 고르게 한다.
3. **비슷하게는 만들되 똑같이는 만들지 않는다.** 원본의 문구·일러스트·사진·로고를 그대로 옮기지 않고, 구도·배치를 하나하나 맞춰 복제하지 않는다. 레퍼런스 이미지를 잘라 붙이거나 편집 원본으로 쓰지 않는다 — 그림은 새로 만든다.
4. "비슷한 느낌으로"는 그대로 진행한다. 사용자가 "똑같이" 만들어 달라고 하면 금지사항 문서의 답변 방식대로 답하고, 비슷한 분위기의 새 시안으로 진행한다.

**글꼴 정하기** — 자세한 기준은 `references/글꼴_규칙.md`

1. **사용자가 고른 글꼴이 있으면** 그것을 쓴다. 대신 바꾸지 않는다. 가독성이 걱정되면(장식체를 작은 본문에 쓰는 경우 등) 이유를 한 줄로 말하고 사용자 결정을 따른다.
2. **없으면 AI가 눈누 무료 글꼴 전체에서 고른다.** 품목·분위기·레퍼런스에 맞춰 제목용·본문용 방향을 정하고, `python scripts/fetch_font.py --tag <태그>`(또는 `--search <키워드>`)로 후보를 찾는다. 고른 글꼴과 이유를 한 줄씩 알린다. 사용자가 바꾸자고 하면 바꾼다.
3. **인쇄 사용 가능 확인** — `fetch_font.py <눈누 링크> --list`로 눈누 라이선스 요약표의 「인쇄」 줄을 본다. **「사용 가능」인 글꼴만 쓴다.**
4. **파일 받기** — `python scripts/fetch_font.py <눈누 링크> --weight <굵기> --out fonts` (400=Regular, 500=Medium, 700=Bold). 인쇄용 TTF·OTF로 저장하고 spec.fonts에 넣을 값을 출력한다. **[받기 실패]가 나올 때만** 이유를 한 줄로 말하고 TTF·OTF 파일 첨부를 요청한다(그래픽은 먼저 만들어도 된다).
5. 사용자가 파일만 첨부하고 링크가 없으면 눈누 링크를 요청한다 — 사용 글꼴 안내에 링크가 들어가야 한다.
6. **역할 배정** — 굵거나 장식이 강한 쪽 → 제목, 고른 쪽 → 본문. 한 줄로 알린다. 가변 글꼴은 쓰지 않는다.

## 3단계 · 배경과 그래픽을 만든다

**원칙: 이미지 모델로 만드는 그림은 전부 배경이 투명한 PNG다.** 바탕(배경색)은 이미지가 아니라 spec의 `background`(CMYK 단색·그라데이션)로 깔고, 그 위에 투명 PNG 그래픽과 글자를 층으로 쌓는다.

```text
바탕: CMYK 단색·그라데이션(벡터)  →  그래픽: 투명 PNG(이미지 모델)  →  글자·도형·로고(벡터·원본)
```

- 바탕색이 CMYK 값 그대로 인쇄된다 — 이미지 변환으로 색이 탁해지지 않는다.
- 그래픽을 옮기거나 크기를 바꾸거나 빼기 쉽다. 긴 현수막도 바탕은 벡터라 흐려지지 않는다.
- 사용자가 사진 배경을 직접 준 경우에만 `background.type: image`로 깐다(이미지 모델로 만든 그림은 바탕으로 쓰지 않는다).

**구성 예**

| 품목 | 바탕(벡터) | 투명 PNG 그래픽 |
|---|---|---|
| 초청장·감사장·포스터 | 단색 또는 그라데이션 | 장식 1~3개(꽃·리본·추상 곡선·빛 번짐 등), 모서리·하단 배치 |
| 가로세로 비율이 3:1보다 긴 현수막 | 단색 또는 그라데이션 | 좌우 끝 장식 1~2개(작게 — 크게 늘리면 흐려진다) |
| 단정한 문서형(감사장 등) | 단색 + 테두리 도형(rect) | 없음 또는 작은 문양 1개 |

**이미지 모델 프롬프트 규칙**

- **"transparent background, PNG"를 반드시 적는다.** 배경을 칠하지 말고, 그림 바깥은 완전히 투명하게 만들라고 한다. 그림자·빛 번짐도 투명 위에 얹힌 형태로 만든다.
- 하나의 그래픽(장식 한 덩어리)만 그리게 한다. 장면 전체·액자·바닥 면을 그리지 않는다.
- **글자·숫자·로고·서명·워터마크를 넣지 않는다**고 반드시 적는다. "no text, no letters, no logo"를 함께 쓴다.
- 가능한 가장 큰 크기로 만든다(긴 변 1500px 이상). 가는 선·작은 패턴은 피한다.
- 실루엣·아이콘처럼 **색 수가 적은 플랫 스타일**로 만들 수 있으면 그렇게 한다 — 벡터로 바뀌어 아무리 크게 뽑아도 선명하다.
- 실존 인물·특정 작가 화풍·다른 회사 상표를 넣지 않는다.

예시

```text
기업 VIP 초청장용 장식 그래픽. 금색 빛 번짐과 부드러운 추상 곡선 3개가 겹친 우아한 장식 한 덩어리.
transparent background, PNG, 그림 바깥은 완전히 투명. 바탕색·액자·바닥 면 없음.
no text, no letters, no numbers, no logo, no watermark.
```

**인쇄용으로 다듬기 — 그래픽마다 반드시** `scripts/prep_graphic.py`를 돌린다. 그래픽이 인쇄물에 놓일 가로 크기(mm)를 먼저 정하고 넣는다.

```bash
python scripts/prep_graphic.py deco.png --width-mm 1300 --item-mm 5000   # 현수막 5000mm에 1300mm 폭으로 놓을 그래픽
```

스크립트가 알아서 하는 일:

1. **바탕 지우기** — 그림 바깥이 투명하지 않으면(흰 바탕 등) 가장자리와 이어진 바탕색을 지운다. 바탕이 고르지 않아 지울 수 없으면 `[다시 만들기]`를 내니, 이미지 모델에 투명 배경으로 다시 만들어 달라고 한다. **오브젝트 뒤에 바탕이 남은 채로 쓰지 않는다.**
2. **여백 자르기** — 투명한 바깥 여백을 잘라 실제 그림 크기로 맞춘다.
3. **종류에 따라 처리**
   - **플랫 그래픽**(실루엣·아이콘·단색 도형처럼 색이 몇 개뿐) → **벡터로 변환**(`<이름>_vector.json`). 크기와 상관없이 선명하고 색이 CMYK로 정확하다. spec에 `"type": "vector"`로 넣는다.
   - **그라데이션·질감·빛 번짐·사진 느낌** → 이미지 그대로 두고, 인쇄 크기에 필요한 해상도(실제 크기 기준 종이 300dpi · 2000mm 미만 150dpi · 현수막 50dpi)까지 **고품질로 키운다**(`<이름>_print.png`). spec에 `"type": "image"`로 넣는다.
4. spec에 넣을 요소 예시를 출력한다.

- 4배 넘게 키워야 한다는 경고가 나오면 해상도 수치는 맞아도 세부가 흐릴 수 있다. 사용자에게 알리고 ① 그래픽을 더 작게 배치 ② 이미지 모델로 더 크게 다시 생성 ③ 플랫 스타일로 바꿔 벡터 처리 중에서 고르게 한다.
- 플랫 그래픽으로 판정됐는데 벡터로 바꾸면 안 되는 그림(미묘한 음영이 중요한 경우)이면 `--mode raster`로, 반대면 `--mode vector`로 강제한다.
- **결과물을 바로 인쇄소에 넘길 수 있게 하는 것이 목표다.** 조립 스크립트가 「실효 ○○dpi — 목표보다 낮습니다」를 내면 그 그래픽은 아직 처리되지 않은 것이다. prep_graphic.py로 처리한 뒤 다시 조립한다.

만든 그래픽을 바탕색 위에 얹은 모습으로 사용자에게 보여 주고 확인을 받는다. 마음에 들지 않으면 다시 만든다.

## 4단계 · 파일을 조립한다

prep_graphic.py로 처리한 그래픽(`_vector.json` · `_print.png`)으로 `spec.json`을 쓴 뒤 스크립트를 실행한다.

```bash
python scripts/build_print.py spec.json
```

필요 라이브러리: `reportlab`, `pymupdf`, `pillow`, `fonttools`, `numpy`, `brotli`(눈누 글꼴 파일 변환), `scikit-image`(그래픽 벡터 변환). 없으면 `pip install reportlab pymupdf pillow fonttools numpy brotli scikit-image`.
OTF 글꼴은 스크립트가 TTF로 바꿔 쓴다(처음 한 번 1분 안팎).

**글자 빠짐 검사** — 스크립트는 조립 전에 모든 문구의 글자가 글꼴에 있는지 검사하고, 없으면 멈춘다(장식체·손글씨는 한글 일부, `○`·`※`·`★`·영문·숫자가 빠진 경우가 많다). 멈추면 빠진 글자를 사용자에게 보여 주고 고르게 한다.

```text
「○○체」에 아래 글자가 없어 그대로 인쇄하면 빈칸으로 찍힙니다: ★ ○
① 빠진 글자만 본문 글꼴로 찍기  ② 다른 글꼴로 바꾸기  ③ 문구에서 빼기
```

①이면 해당 글꼴에 `"fallback": "본문"`을 넣어 다시 실행한다.

**spec.json** — 좌표·크기는 mm, 기준점은 **완성 크기 왼쪽 위**. 글자 크기만 pt.

```json
{
  "output_name": "VIP초청장_시안1",
  "trim_mm": [127, 178],
  "bleed_mm": 2,
  "safe_mm": 5,
  "crop_marks": false,
  "background": {"type": "gradient", "colors": ["cmyk(100,85,20,45)", "cmyk(90,70,10,20)"]},
  "fonts": {
    "제목": {"file": "fonts/제목글꼴-Bold.ttf", "name": "○○체 Bold", "noonnu": "https://noonnu.cc/font_page/번호"},
    "본문": {"file": "fonts/본문글꼴-Regular.ttf", "name": "△△ Regular", "noonnu": "https://noonnu.cc/font_page/번호"}
  },
  "elements": [
    {"type": "image", "path": "deco_print.png", "x": 0, "y": 110, "w": 127},
    {"type": "image", "path": "logo.png", "x": 48.5, "y": 14, "w": 30},
    {"type": "text", "text": "2027 고객 초청 세미나", "x": 10, "y": 40, "w": 107,
     "size": 22, "font": "제목", "color": "cmyk(0,0,0,0)", "align": "center"},
    {"type": "line", "x": 43.5, "y": 62, "x2": 83.5, "y2": 62, "color": "cmyk(20,30,65,0)", "width_pt": 0.8},
    {"type": "text", "text": "일시  2027. 3. 18.(목) 14:00\n장소  ○○호텔 그랜드볼룸", "x": 10, "y": 128, "w": 107,
     "size": 10, "font": "본문", "color": "cmyk(0,0,0,0)", "align": "center", "leading": 1.6},
    {"type": "rect", "x": 0, "y": 168, "w": 127, "h": 12, "fill": "cmyk(20,30,65,0)", "allow_bleed": true}
  ]
}
```

| 항목 | 값 |
|---|---|
| `background.type` | `color`(color) · `gradient`(colors 배열, direction `vertical`/`horizontal`) — 기본. `image`(path)는 사용자가 사진 배경을 직접 줬을 때만 |
| `fonts` | 이름(예: `제목`·`본문`) → `file`(fetch_font.py로 받은 파일 또는 사용자가 첨부한 파일) · `name`(글꼴 이름·굵기) · `noonnu`(그 글꼴의 눈누 페이지 주소) · `fallback`(선택, 빠진 글자를 대신 찍을 글꼴 이름). **`name`·`noonnu`가 비면 스크립트가 멈춘다** — 저작권 확인용 |
| `text` | `text`(줄바꿈 `\n`) · `x` `y` `w`(폭을 주면 자동 줄바꿈·정렬) · `size`(pt) · `font`(`fonts`의 이름, 생략 시 첫 번째) · `color` · `align`(`left`/`center`/`right`) · `leading`(줄 간격 배수) · `letter_spacing`(pt) |
| `rect` | `x` `y` `w` `h` · `fill` · `stroke` · `stroke_pt` · `radius` · `allow_bleed`(재단선 밖까지 나가는 띠 장식이면 `true`) |
| `line` | `x` `y` `x2` `y2` · `color` · `width_pt` |
| `vector` | `path`(prep_graphic.py가 만든 `_vector.json`) · `x` `y` `w`(`h` 생략 시 비율 유지) — 플랫 그래픽. CMYK 도형으로 그려져 크기와 상관없이 선명 |
| `image` | `path` · `x` `y` `w`(`h` 생략 시 비율 유지) — 로고는 이미지 모델로 다시 그리지 말고 사용자 원본 파일을 쓴다. CMYK로 바꿔 넣는다. 투명 배경 PNG는 투명한 부분이 그대로 비친다 |
| `color` | **CMYK로 지정한다** — `"cmyk(C,M,Y,K)"`(각 0~100%) 또는 `[C,M,Y,K]`. `K100` = 인쇄용 검정(먹 1도), `cmyk(0,0,0,0)` = 종이색(흰색). `#RRGGBB`도 받지만 CMYK로 바꿔 쓰고 알린다 — 회사 색처럼 정확해야 하는 색은 CMYK 값을 받아서 쓴다 |
| `icc` | (선택) 인쇄소가 준 CMYK ICC 프로파일 경로. 있으면 그래픽·로고 이미지를 이 프로파일로 바꾼다. 없으면 기본 변환식(회색·검정은 K로) |
| `bleed_mm` · `safe_mm` | **품목별 기본값을 쓴다** (`references/규격표.md` 「품목별 기본값」) — 종이 인쇄물 2 · 5 / 현수막·족자 **0** · 30 / 세로배너 **0** · 20(위아래는 50mm 안쪽에 배치). 인쇄소 지정값이 있으면 그 값 |
| `crop_marks` | 재단선 표시. 기본 `false`. **인쇄소가 요구할 때만** `true` — 현수막·배너에는 넣지 않는다 |
| `scale` | 파일 축척. **현수막급(긴 변 2000mm 이상)은 생략 시 0.5 — 50% 축소 파일**로 만든다(좌표·글자 크기는 실제 크기 그대로 적는다. 스크립트가 줄인다). 인쇄소가 원본 크기를 요구하면 `1`, 1/10 크기를 요구하면 `0.1`. 그 밖의 인쇄물은 실제 크기(`1`) |
| `pdf_only` | **현수막류(현수막·족자·손잡이 현수막)는 `true`** — PDF 하나만 만든다(PNG·JPG는 용량이 크고, 필요하면 PDF에서 이미지로 저장할 수 있다). 재단선 표시도 자동으로 빠진다. 배치 확인용 미리보기는 `.check/`에만 작게 만든다 |
| `dpi` | 생략하면 크기에 맞춰 자동(300/150/100) |

**CMYK 색 고르는 원칙**

- 작은 글자(12pt 미만)의 검정은 **`K100`**. 4색을 섞은 검정은 판이 조금만 어긋나도 글자가 번진다. 스크립트가 경고한다.
- 넓은 면의 진한 색은 잉크 총량(C+M+Y+K) **300% 이하**. 넘으면 뒷묻음이 생긴다. 스크립트가 경고한다.
- 넓은 검정 배경은 K100만 쓰면 회색빛이 돈다 → `cmyk(40,30,30,100)` 같은 리치 블랙(넓은 면에만).
- 형광·네온색, 아주 밝은 RGB 색(화면용 파랑·초록)은 CMYK로 나오지 않는다. 처음부터 CMYK 안에서 고른다.
- 사용자가 회사 색을 `#RRGGBB`로만 주면 CMYK 값이 있는지 묻는다(회사 디자인 가이드에 보통 있다). 없으면 변환해 쓰고 그렇게 알린다.

**배치 원칙**

- 글자·로고는 안전선 안(종이 5mm, 현수막·족자 30mm, 세로배너 좌우 20mm·위아래 50mm)에 둔다. 스크립트가 벗어난 요소를 알려 준다.
- 정보 위계는 3단계 이내 — 제목 / 핵심 정보(일시·장소) / 부가 정보.
- 글자 크기 하한 — 초청장·감사장 본문 9pt 이상, 포스터 본문 24pt 이상, 현수막 제목은 세로 높이의 30~45%.
- **`elements`는 적힌 순서대로 아래에서 위로 쌓인다.** 그래픽(투명 PNG)을 글자보다 먼저 적으면 글자 아래에, 나중에 적으면 위에 놓인다. 로고는 보통 맨 뒤에 적는다.
- 글자와 바탕·그래픽의 대비를 확인한다. 그래픽 위 글자가 잘 안 보이면 그래픽을 옮기거나 **단색 띠(rect)**를 깔아 준다.

## 5단계 · 확인한다

스크립트가 만든 확인용 이미지를 열어 직접 본다 — 종이 인쇄물은 `*_확인용_재단선.png`, 현수막류(`pdf_only`)는 `.check/*_배치확인.png`.

- [ ] 빨간 선(재단선)·파란 선(안전선) 안에 글자·로고가 모두 들어와 있다
- [ ] 글자가 잘리거나 겹치지 않았다. 한 단어가 줄바꿈으로 쪼개지지 않았다
- [ ] 모든 그래픽이 prep_graphic.py를 거쳤다(`_vector.json` 또는 `_print.png`). 오브젝트 뒤에 네모난 바탕이 보이지 않는다. 그래픽에 글자·로고 비슷한 것이 생기지 않았다
- [ ] 스크립트 경고(해상도 낮음, 안전선 밖, 7pt 미만)를 처리했다 — 해상도 경고가 남은 채로 넘기지 않는다

문제가 있으면 spec.json을 고쳐 다시 실행한다. 사용자에게 보여 주기 전에 스스로 고친다.

## 6단계 · 넘긴다

**넘기는 파일**

| 품목 | 넘기는 파일 |
|---|---|
| 종이 인쇄물 (초청장·감사장·포스터·전단 등) | `○○_인쇄용.pdf`(발주용, 재단 여백 포함) · `○○.png`(공유·검토) · `○○.jpg`(미리보기) · `○○_확인용_재단선.png`(확인용) |
| **현수막류** (현수막·족자·손잡이 현수막) | **PDF 하나만.** 재단선 표시 없음. `.check/` 미리보기는 넘기지 않는다. 현수막급(긴 변 2000mm 이상)은 **50% 축소 파일** `○○_인쇄용_50%축소.pdf`, 족자·손잡이 현수막은 완성 크기 `○○_인쇄용.pdf` |

**결과 메시지 순서** — 매번 이 순서로 쓴다.

1. **[사용 글꼴]** — 매번.
2. **[초안 안내]** — 매번.
3. **[발주 전 확인]** — 매번, 이 품목에 맞는 항목 3줄 이내(`references/인쇄발주_주의사항.md`).
4. **[현수막 발주 파일 안내]** — **현수막급(긴 변 2000mm 이상)이면 반드시.** 스크립트가 출력한 안내를 그대로 옮긴다. 빠뜨리지 않는다.

```text
[현수막 발주 파일 안내]
- 이 PDF는 50% 축소 파일(2500x450mm)입니다. 발주서에 「50% 축소 파일 — 2배 확대해 5000x900mm로 출력」이라고 적어 주세요.
- 글자·도형은 벡터라 크게 늘려도 선명합니다. 그래픽 이미지는 실제 크기 기준으로 확인한 해상도입니다.
- 인쇄소마다 받는 파일 크기가 다릅니다. 인쇄소가 원본 크기(실제 크기) 또는 1/10 크기 파일을 요구하면,
  「원본 크기로 다시 만들어 줘」 또는 「1/10 크기로 다시 만들어 줘」라고 요청해 주세요.
```

사용자가 원본 크기·1/10 크기를 요청하면 spec의 `scale`만 `1` 또는 `0.1`로 바꿔 다시 만든다(배치는 그대로).

(주의사항 고지는 이 대화의 첫 최종 답변 맨 앞에 한 번 넣는다 — 맨 위 「첫 호출 고지」. 결과를 넘기는 답변이 첫 최종 답변이면 결과 위에 고지를 놓는다.)

**1. 사용 글꼴** — 스크립트가 출력한 [사용 글꼴] 목록을 그대로 옮긴다. 글꼴을 바꿔 다시 만들 때마다 다시 쓴다.

```text
[사용 글꼴] 인쇄 전에 눈누 페이지에서 라이선스를 직접 확인해 주세요.
- 제목: ○○체 Bold · https://noonnu.cc/font_page/○○○
- 본문: △△ Regular · https://noonnu.cc/font_page/△△△
```

스크립트는 그 아래에 **「skill 내부 확인용」 파일 대조**(첨부 파일 안에 적힌 글꼴 이름)도 출력한다. 이 부분은 사용자에게 보여 주지 않는다. 파일이 spec의 글꼴 이름과 **분명히 다른 글꼴일 때만**(같은 글꼴의 영문·한글 표기 차이는 제외) 「○○ 파일은 △△ 글꼴로 보입니다. 맞는지 확인해 주세요」라고 알린다.

**2. 초안 안내**

```text
[초안 안내] 이 파일은 초안입니다. 크기·재단 여백·안전선은 대표 규격 기준이므로,
발주하실 인쇄소의 작업 규격(작업 크기, 재단 여백, 파일 형식, 색상 모드)을 확인하신 뒤
「인쇄소 규격은 ○○입니다」라고 알려 주시면 그 값으로 고쳐 최종본을 만들어 드립니다.
```

**3. 발주 전 확인** — 이 품목에 맞는 것만 3줄 이내. 예: 발주서에 적을 완성 크기 · 교정본으로 색 확인 요청 · 더미 문구를 실제 내용으로 바꿨는지.

**인쇄소 요구사항을 받으면** 그 값으로 spec.json의 `trim_mm`·`bleed_mm`·`safe_mm`·`crop_marks`·`dpi`를 고치고, 배치가 새 안전선을 벗어나면 다시 배치한 뒤 다시 만든다. 이때 파일 이름에 `_최종`을 붙인다. 현수막류는 인쇄소가 PNG·JPG를 요구할 때만 `pdf_only`를 끈다. 인쇄소가 받는 파일 축척(원본·1/10 등)을 말하면 `scale`을 그 값으로 한다. 인쇄소가 ICC 프로파일을 주면 `icc`로 지정해 다시 만든다. PDF/X 규격처럼 이 skill이 만들 수 없는 조건이면 그렇다고 말하고, 인쇄소에 변환을 요청하도록 안내한다.

수정 요청을 받으면 spec.json만 고쳐 다시 만든다. 그래픽을 새로 만들 때만 3단계로 돌아간다.
